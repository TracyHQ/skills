# Two batches for the same site

The site is invented: a small web agency in Germany that builds and maintains Joomla sites for
regional businesses. Their pages address the reader formally, they publish no prices, and they
have no reference page, because they do not name their clients.

Read `failing/` first. Every fault in it is one an agent produces on its own, and each one reads
fine until you check it.

| | |
|---|---|
| `passing/` | what a batch looks like when the rules held |
| `failing/` | the same batch with six faults, each named in its own `WHY-IT-FAILS.md` |

Both are trimmed to one article. The shape is the point, not the volume.
